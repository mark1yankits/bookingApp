### 2.4. Проектування API

**Текст для розробки:**
Охарактеризувати RESTful API архітектуру та основні endpoints системи. Authentication routes: POST /auth/register для реєстрації нового користувача, POST /auth/login для входу в систему, GET /auth/me для отримання інформації про поточного користувача. Properties routes: GET /properties для отримання списку оголошень з підтримкою фільтрів (мінімальна/максимальна ціна, локація), GET /properties/:id для отримання деталей конкретного оголошення, POST /properties для створення нового оголошення (тільки для host/admin), GET /properties/host/my-properties для отримання оголошень поточного власника. Messages routes: GET /messages/property/:propertyId для отримання повідомлень по оголошенню, POST /messages для відправки повідомлення, GET /messages/property/:propertyId/participants для отримання учасників чату. Reviews routes: GET /reviews/property/:propertyId для отримання відгуків, POST /reviews для створення відгуку. Weather routes: GET /weather/:location для отримання інформації про погоду. Описати формат запитів та відповідей, коди статусів HTTP, обробку помилок.
